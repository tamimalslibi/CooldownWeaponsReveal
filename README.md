# CooldownDisplay

Shows a colored boss-bar cooldown for each of your custom weapons — only while
you're carrying that specific weapon.

## What it does
- When a player right-clicks with a tracked weapon, its cooldown starts.
- Every few ticks, the plugin checks: is this player carrying the weapon,
  AND is it on cooldown? If both are true, a colored boss bar shows the
  weapon's name and remaining time. Otherwise the bar disappears.
- Multiple weapons on cooldown at once just stack as separate boss bars.

## Weapons configured (edit anytime in config.yml, no recompile needed)
| Weapon              | Color            | Default cooldown |
|---------------------|------------------|-------------------|
| Dash Sword          | Lime Green       | 8s                |
| Lighting Sword      | Yellow           | 10s               |
| Dash Mace           | Blue/Dark Blue   | 12s               |
| Saturation Spear    | Pink             | 15s               |
| Dash Spear          | Orange           | 8s                |
| Dashbow             | Red              | 10s               |

I picked cooldown lengths as placeholders since you didn't specify them —
change `cooldown-seconds` per weapon in `config.yml`, then run `/cd reload`.

**Important:** the plugin matches weapons by their exact item **display name**
(color codes ignored). So your Dash Sword item must be named exactly
"Dash Sword" (via anvil, /give with a name component, or your custom item
plugin), etc. If your items are generated by another plugin (e.g. a custom
enchant/ability plugin) and already have those exact display names, this
will just work out of the box.

## "On you" behavior
By default `require-in-hand: false` in config.yml, meaning the cooldown bar
shows if the weapon is ANYWHERE in your inventory (hotbar, inventory slots,
offhand). Set it to `true` if you only want it to show while actively held
in your hand/offhand.

## Building
You'll need Maven and internet access (to pull the Paper API dependency):

```
cd CooldownDisplay
mvn clean package
```

The compiled plugin will be at `target/CooldownDisplay.jar`. Drop that into
your server's `plugins/` folder and restart (or `/reload`, though a restart
is safer).

## Commands
- `/cd reload` — reload config.yml without restarting the server
  (permission: `cooldowndisplay.admin`, default: op)

## Notes / things you may want to tweak
- Cooldown trigger is currently "right-click with the item in main hand."
  If your abilities actually trigger differently (e.g. left-click, sneak +
  right-click, or through your ability plugin's own API/event), let me know
  and I'll wire ItemListener to that instead.
- Boss bars have a fixed vanilla color palette (BLUE, GREEN, PINK, PURPLE,
  RED, WHITE, YELLOW) — orange isn't available for the bar fill itself, so
  Dash Spear's bar renders as yellow, but its TEXT is exact orange (#FFA500)
  since text colors support full hex.
